# Мост на GitHub — бесплатно, без включённого ПК

Репозиторий уже создан и файлы загружены. Workflow **Bridge** работает непрерывной цепочкой: каждый запуск обрабатывает сообщения ~4 минуты, а затем сам запускает следующий. Сообщения из MAX приходят в Telegram с задержкой ~4–6 минут и закрепляются.

Осталось сделать один раз четыре шага.

## 1. Создайте ботов и возьмите токены

- MAX: на платформе dev.max.ru создайте бота и скопируйте его токен.
- Telegram: напишите @BotFather команду `/newbot` и скопируйте токен.

## 2. Добавьте токены в Secrets

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**.

| Имя секрета | Значение |
|---|---|
| `MAX_TOKEN` | токен MAX-бота |
| `TG_TOKEN` | токен Telegram-бота |

Токены нельзя класть в файлы репозитория — он публичный. Secrets хранятся зашифрованными, их не видно никому.

## 3. Добавьте ботов в группы

- MAX: добавьте бота в группу и **назначьте администратором** (без этого он не видит сообщения).
- Telegram: добавьте бота в группу и дайте право **закреплять сообщения**.

## 4. Запустите Init

1. Вкладка **Actions** → слева **Init** → справа **Run workflow**.
2. Сразу после запуска напишите любое сообщение в группу MAX — скрипт ждёт его до 2 минут.
3. Потом напишите сообщение в Telegram-группу — на это ещё 2 минуты.

ID групп определятся и сохранятся автоматически, никуда копировать их не нужно. Если скрипт не дождался сообщения — просто запустите Init ещё раз, уже найденный ID он не потеряет.

## Проверка

Напишите сообщение в группу MAX — через 4–6 минут оно появится в Telegram закреплённым. Во вкладке Actions запуски Bridge должны появляться один за другим непрерывно.

## Админ-команды

Команды можно писать **в группу MAX** или **в Telegram-группу** — от имени администратора (по умолчанию это владелец ботов; список ID задаётся в config.json ключами `max_admin_ids` / `tg_admin_ids`). Ответ приходит туда же, где написана команда.

| Команда | Действие |
|---|---|
| `/list` | последние 20 отправителей с их ID |
| `/rules` | текущие правила по отправителям |
| `/block <id>` | не пересылать сообщения этого отправителя |
| `/unblock <id>` | снять запрет |
| `/nopin <id>` | пересылать сообщения, но без закрепа |
| `/pin <id>` | снова пересылать с закрепом |
| `/unpin` | снять последний закреп в Telegram-группе |
| `/unpinall` | снять все закрепы |
| `/help` | справка |

Правила и список отправителей хранятся в state.json и переживают перезапуски (кэш Actions). Команды обрабатываются в том же запуске цепочки, что и сообщения, — реакция занимает до ~30 секунд.

## Примечания

- Если мост работал на вашем ПК или сервере — остановите его там, иначе сообщения будут дублироваться.
- Чтобы сменить группу: Settings → Actions → Caches → удалите кэши `bridge-state-*` и запустите Init заново.
- Если цепочка запусков прервалась (в Actions нет новых запусков дольше 10 минут) — нажмите **Run workflow** у Bridge один раз, и она возобновится.
